# Portfolio

A simple and modern **portfolio website** built with **Next.js**, **Tailwind CSS**, and **Formspree**.

🔗 **Live Demo:** [https://wareesha-jannat-portfolio.vercel.app](https://wareesha-jannat-portfolio.vercel.app)

## Tech Stack

- Next.js
- Tailwind CSS
- Formspree

## Features

- Responsive design
- Clean UI
- Contact form integration

## Getting Started

```bash
npm install
npm run dev
```

## Contact Form

Powered by **Formspree**. Replace the form action with your Formspree endpoint.
